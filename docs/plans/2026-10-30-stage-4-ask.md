## Contract

- Request: `{ "question": string (1–500 chars), "top": int? (1–10, default 5) }`
- Response 200: `{ answer, grounding: { status: grounded|abstained|unverified, reason? }, citations: [{ n, source, heading, startLine, endLine, distance }], retrieval: { chunker, top, bestDistance, gate }, usage: { model, inputTokens, outputTokens }, timings: { retrievalMs, generationMs } }`
- Errors: 400 `invalid_request`, 409 `collection_missing`, 429 `rate_limited`, 502 `embedding_unavailable` / `provider_unavailable` / `reply_unreadable` / `reply_cut_off`, 503 `vector_store_unavailable`

## Flow

validate → retrieve (heading chunker, top k) → gate (no hits or best distance > `Ask:MaxDistance` → abstained, no model call) → assemble numbered `<source n=…>` blocks + `prompts/ask-v1.md` → `IChatClient` typed `AskAnswer` (one repair call if unreadable; cut off → 502) → `CitationCheck` → grounded / abstained / unverified. Citations in the response come from the server's map n → `SearchHit`, never from the model.

## Decisions & trade-offs

- Retrieval uses the heading chunker (section 12 of `experiments.md`: heading had more rank-1 hits and no miss on the 5 questions).
- A distance gate abstains before generation when there are no hits or the best distance is above `Ask:MaxDistance` (0.50 to start, calibrated in 4.8), so unrelated questions cost no model call.
- The model can also abstain through `NotInDocs` for near-misses that pass the gate.
- Citations in the response are built by the server from its n → `SearchHit` map, never taken from the model; `CitationCheck` compares the model's cited numbers against that map.
- Typed output without the native JSON-schema format (`useJsonSchemaResponseFormat: false`, as `JobExtractor`, because of Haiku), parsed with `StructuredReply.TryParse`, with one repair call; a cut-off reply is a 502.
- Rate limit 10 requests/min per IP.
